Стенд передних домкратов ​

Это стенд передних домкратов, для которого подготовлен ROS 2 ↔ CAN bridge в third_party/am-ros2-can-bridge.

На стенде проверяются два гидравлических домкрата, концевики, датчики длины, положение клапанов, общее давление гидролинии и состояние CAN-узлов.

По конфигурации front_jacks_stand_canonical.yaml используются такие CAN-узлы:

Подготовка CAN ​

На Jetson этот шаг может быть уже выполнен системной конфигурацией. Перед запуском bridge проверьте, что нужный SocketCAN-интерфейс существует:

bash
ip link show slcan0

На ноутбуке с USB-CAN/slcan адаптером поднимите интерфейс из bridge repository:

bash
cd third_party/am-ros2-can-bridge
make can_create_slcan CAN_SLCAN_DEVICE=/dev/ttyACM0 CAN_IFACE=slcan0

Для SITL без реального CAN-адаптера используйте virtual CAN из корня firmware:

bash
make create_slcan0

Запуск bridge ​

На хосте с ROS 2 Jazzy:

bash
cd third_party/am-ros2-can-bridge
make host_run CONFIG=front_jacks_stand_canonical.yaml

Если ROS 2 на хосте не установлен, можно запустить bridge в Docker:

bash
cd third_party/am-ros2-can-bridge
make docker_interactive
./bridge.py --config front_jacks_stand_canonical.yaml --verbose

Проверка ​

Список topics:

bash
ros2 topic list

Статус CAN-узлов:

bash
ros2 topic echo /diagnostics/can/node_status

Команда на правый домкрат:

bash
ros2 topic pub --once /actuator/hydraulic/jack_rod_fr_joint active_drill_msgs/msg/HydraulicCmd "{flow_cmd: 0.25, pressure_limit: 0.0}"

Эмулятор CAN-узлов для проверки bridge без реального стенда:

bash
cd third_party/am-ros2-can-bridge
./tests/emulate_front_jacks_stand_nodes.py

GUI для проверки canonical topics:

bash
cd third_party/am-ros2-can-bridge
make docker_interactive
./tests/canonical_stand_gui.py

GUI запускается из Docker interactive shell, где уже установлены ROS 2 зависимости, active_drill_msgs и python3-tk. На Linux desktop для отображения окна может понадобиться разрешить локальный X11-доступ перед запуском контейнера:

bash
xhost +SI:localuser:root
