Настройка INA228 ​

Прошивка INA228 поддерживает двенадцать фиксированных адресов INA228, предусмотренных для AM_NODE_V2. Один и тот же модуль используется в прошивках узлов на F1 и H7. Особенности подключения и найденная ошибка адресации LOAD3 описаны в карте адресов AM_NODE_V2.

Настройка ​

Параметры ina.c_sens1.role…ina.c_sens4.role задают назначение входов C_SENS1–4 с адресами 0x40–0x43: отключён (0), ток (1), давление (2) или длина (3). По умолчанию публикуется ток C_SENS1; остальные каналы C_SENS и публикации каналов нагрузки отключены. В сообщениях тока и длины входам C_SENS1–4 соответствуют идентификаторы цепи или датчика 0–3. Для каналов нагрузки следует выбирать идентификаторы цепей, не совпадающие с идентификаторами других источников CircuitStatus на узле.

Ток рассчитывается по формуле I[A] = Vshunt[uV] / Rshunt[uOhm]. Параметр ina.sensor_shunt_uohm применяется только к каналам C_SENS в режиме измерения тока; значение по умолчанию — 20. Для шунтов C_SENS номиналом 2 Ом на AM_NODE_V2 необходимо установить 2000000. Для тока нагрузки используются ina.load_shunt_uohm со значением по умолчанию 20000 (20 мОм) и коэффициент фильтра ina.current.filter_percent, по умолчанию 20 процентов. Параметры идентификаторов цепей ina.load1.in.circuit_id…ina.load4.out.circuit_id включают публикацию при неотрицательном значении; -1 отключает канал.

Калибровка давления и длины задаётся граничными значениями тока из спецификации датчика, в целых миллиамперах. Для каждого канала параметры .current.in_min_ma и .current.in_max_ma по умолчанию равны 4 и 20. Текущий интерфейс целочисленных параметров не поддерживает дробные значения миллиампер; сами измерения при этом не округляются до целых миллиампер. Прошивка пересчитывает границы с учётом фиксированных шунтов C_SENS номиналом 2 Ом (1 мА = 2000 мкВ), независимо от ina.sensor_shunt_uohm. Поэтому режимы давления и длины требуют входов с шунтами 2 Ом. Границы давления задаются параметрами .pressure.out_min_pa и .pressure.out_max_pa, а длины — .length.out_min_mm и .length.out_max_mm; длина публикуется в метрах. Входное значение ограничивается интервалом калибровки; обратный порядок границ позволяет инвертировать зависимость. Если границы калибровки совпадают, при токе не выше этой границы выбирается значение .pressure.out_min_pa или .length.out_min_mm, а при превышении — .pressure.out_max_pa или .length.out_max_mm. Для датчика длины 4–20 мА с диапазоном 0–1000 мм на C_SENS2 необходимо задать ina.c_sens2.role = 3, ina.c_sens2.current.in_min_ma = 4, ina.c_sens2.current.in_max_ma = 20, ina.c_sens2.length.out_min_mm = 0 и ina.c_sens2.length.out_max_mm = 1000. Для датчика давления следует выбрать режим 2 и задать физические границы в паскалях согласно спецификации датчика.

Несколько каналов длины публикуются независимо друг от друга. Поскольку сообщение StaticPressure не содержит идентификатора датчика, давление публикует только исправный канал с наименьшим номером. При его отказе публикация переключается на следующий исправный канал; после восстановления приоритет возвращается каналу с меньшим номером. При настройке нескольких каналов давления необходимо учитывать этот порядок выбора источника.

Периодичность опроса и обработка отказов ​

Модуль обслуживает не более одного устройства за вызов с периодом 5 мс; целевая частота опроса каждого включённого канала — 10 Гц. Проверка идентификаторов устройства и чтение измерений выполняются в разных вызовах. После успешной инициализации шина повторно не инициализируется; при ошибке инициализации или недоступности устройства попытки повторяются раз в секунду. Чтение I²C остаётся синхронным, поэтому задержка при отказе ограничивается существующими тайм-аутами HAL; жёсткое время выполнения не гарантируется. Отключённые устройства не опрашиваются. При отказе публикация измерений этого устройства прекращается, остальные каналы продолжают работать; ошибки одного адреса выводятся не чаще раза в секунду. Состояние модуля — OK, если работают все включённые устройства, предупреждение при частичном отказе и ошибка при отказе всех включённых устройств.

Обновление прошивки ​

Состав и порядок параметров изменились, а сохранённые значения хранятся по индексам. Параметры шунтов: ina.load_shunt_uohm для нагрузок и ina.sensor_shunt_uohm для каналов C_SENS в режиме тока; оба значения задаются в микроомах. Параметры .cal_min_uv/.cal_max_uv заменены на .current.in_min_ma/.current.in_max_ma; сохранённые значения в микровольтах нельзя использовать как миллиамперы, автоматического пересчёта нет. Для переноса прежней калибровки входов с шунтами 2 Ом следует разделить границы в микровольтах на 2000; дробный результат нельзя точно представить целочисленным параметром в миллиамперах. После установки этой версии необходимо выполнить Erase All в dronecan_gui_tool и до начала работы заново задать идентификатор узла, калибровку, идентификаторы цепей нагрузки, настройки BYPASS и MAX14906. Нельзя восстанавливать старый файл параметров без переноса настроек INA в новую структуру отдельных каналов. Модули ina234_length и ina234_pressure считаются устаревшими: они предназначены для платы, которая больше не выпускается, и используются только на нескольких оставшихся оценочных платах. Это ограничение относится к модулям, а не к драйверу INA234. Модуль ina228_loads сохранён для совместимости; актуальные прошивки узлов используют ina228_sensor. Модули ina228_loads и ina228_sensor нельзя включать в одну сборку одновременно.
