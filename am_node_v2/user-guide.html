AM_NODE_V2 — руководство пользователя ​

Порядок ввода узла в работу: подключение, проверка, настройка и обновление прошивки. Характеристики, разъёмы и параметры прошивок — в даташите.

Подключение ​

Плату крепят, питают и включают в шину CAN по рекомендациям по применению. Разъёмы и распиновка — в разделе 6 даташита.

Проверка при вводе в эксплуатацию ​

  • Визуальная проверка: полярность XT30, USB-C, CAN, Ethernet, load и sensor connectors.
  • Без питания: проверить сопротивления между Vin_in, 5V, 3V3 и GND.
  • Первое включение от лабораторного БП с ограничением тока: проверить 5 V и все 3.3 V rails.
  • Проверить масштабирование ADC входного напряжения и тока.
  • Для FMU mode: проверить CAN1/CAN2, RX/TX и конфигурацию терминаторов.
  • Для FMU mode: проверить USB enumeration через Type-C.
  • Для FMU mode: проверить доступ к LAN8742A по MDIO и PHY address.
  • Просканировать I2C и подтвердить адреса INA228 для LOAD1…LOAD4 и C_SENS1…C_SENS4.
  • Проверить SPI-связь с MAX14906, nREADY, nFAULT, состояние концевиков и диагностику обрыва питания линий.
  • Проверить BYPASS для LOAD1…LOAD4, отдельно учесть общий BYPASS для LOAD3/LOAD4.
  • Протестировать каждый LOADx, SENSx, C_SENSx канал на токограниченной нагрузке до подключения финальных актуаторов.

Настройка узла ​

  1. Задать уникальный на шине uavcan.node.id и при необходимости имя узла system.name.
  2. Настроить каналы LOAD, bypass и входы SENS по параметрам прошивки, входы C_SENS — по настройке INA228.
  3. Сохранить параметры.

Если на плату ставится прошивка с другим составом параметров, сохранённые значения читаются по новой таблице. Поэтому перед настройкой выполняют Erase All, затем задают параметры заново и сохраняют.

Обновление прошивки ​

Прошивка обновляется через bootloader по CAN с помощью GUI-инструмента:

  1. Подключи плату к питанию и CAN-шине.
  2. Открой GUI-инструмент и выбери нужный узел.
  3. Выбери .bin файл прошивки.
  4. Запусти обновление и дождись завершения загрузки.
  5. После перезапуска проверь, что узел снова появился в сети.

Если обновление не начинается, сначала проверь питание, CAN-H/CAN-L, общий GND, терминаторы и отсутствие конфликта uavcan.node.id.
