am_node_default ​

Плата: AM_CONTROL_NODE_V2

Это базовая прошивка-заглушка для платы am_node. Сейчас она нужна как стартовый firmware target для сборки, настройки node ID, heartbeat и базового статуса узла.

Сообщения ​

Публикует:

Тип сообщенияНазначение
uavcan.protocol.NodeStatusHeartbeat и базовый статус узла.

Подписки:

Тип сообщенияНазначение
-Эта прошивка пока не использует прикладные входящие сообщения.

Обновление прошивки ​

Прошивка обновляется через bootloader по CAN с помощью GUI-инструмента:

  1. Подключи плату к питанию и CAN-шине.
  2. Открой GUI-инструмент и выбери нужный узел.
  3. Выбери .bin файл прошивки.
  4. Запусти обновление и дождись завершения загрузки.
  5. После перезапуска проверь, что узел снова появился в сети.

Если обновление не начинается, сначала проверь питание, CAN-H/CAN-L, общий GND, терминаторы и отсутствие конфликта uavcan.node.id.
