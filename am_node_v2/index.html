Контроллер AM_NODE_V2 ​

Контроллер I/O автономного бурового станка. Плата объединяет вход питания, микроконтроллер, CAN-интерфейсы, USB-C, Ethernet PHY, 4 канала управления клапанами, 8 цифровых сенсорных / I/O-каналы и 4 токовых сенсорных входа (4-20мА).

Плата имеет два взаимоисключающих варианта установки контроллера:

ВариантУстановленный контроллерMCUУровень функцийПримечания
AM_NODE_V2-H7модуль RCL-FMUv6XSTM32H753ПолныйCAN1, CAN2, USB-C, Ethernet PHY, SPI6 MAX14906, выходы клапанов, телеметрия INA.
AM_NODE_V2-F103uMODULE v2STM32F103T8УрезанныйCAN1, выходы клапанов, обработка сенсоров по SPI/I2C. Ethernet/USB-C/CAN2 недоступны без отдельной доработки.

Не устанавливать оба контроллерных модуля одновременно без отдельной проверки электрической совместимости.

Характеристики ​

  • Основной вход питания через разъём Vin1 XT30.
  • Припаиваемый модуль DCDC_LMR16030_MODULE; используется как локальный понижающий преобразователь 5 В от Vin.
  • Контроль входного напряжения:
    • ADC_V_IN через делитель R31=180k / R32=10k.
    • Приближённая формула: Vin = ADC_V_IN * 19.
  • Контроль входного тока через INA169 и шунт R29 = 0.001R.
  • 4 канала нагрузки / клапанов через припаиваемые модули AM_TEST_Valve_Control L1..L4.
  • 8 полевых цифровых I/O / сенсорных линий V_SENSE1..V_SENSE8 через модули AM_TEST_MAX14906ATM+.
  • 4 токовых сенсорных входа C_SENS1..C_SENS4 через INA228 + шунты 2R.
  • Физические шины CAN1 и CAN2 с трансиверами TJA1042TK/3 в варианте H7.
  • Физическая шина CAN1 через установленный uMODULE v2 в варианте F103.
  • Разъём USB-C, разведённый на USB FS пины FMUv6X в варианте H7.
  • 100BASE-TX PHY LAN8742AI-CZ-TR и разъём ETH-LIVOX1 в варианте H7.
  • Локальные стабилизаторы 3.3 В для доменов питания: 3V3@PWR, 3V3_MAX, 3V3@ETH, вспомогательные шины V5_INA / V5_INA_CS.
  • Опциональный драйвер вибро / малого мотора DRV2603RUNR с выходом OUT_P/OUT_M.

Корпус ​

Для применения на буровом станке / мобильной технике снабжается герметичным корпусом с:

  • защитой от пыли, воды и масла;
  • разгрузкой натяжения для всех жгутов;
  • виброустойчивым креплением;
  • сервисным доступом к USB/debug только при необходимости;
  • тепловым путём для DC/DC и модулей ключей нагрузки;
  • разделением полевой проводки и низковольтной логики.

Применение ​

Рекомендации по установке ​

  • Устанавливать только один вариант контроллера:
    • H7: устанавливать область board-to-board FMUv6X; не устанавливать uMODULE.
    • F103: устанавливать uMODULE; не устанавливать модуль FMUv6X и H7-only опциональные цепи, если они не используются осознанно.
  • Устанавливать плату-носитель внутри жёсткого герметичного электронного корпуса.
  • Не допускать, чтобы жгуты JST-XH/JST-GH механически держали плату.
  • Обеспечить фиксацию разъёмов или заливку/разгрузку натяжения для вибраций бурового станка.
  • По возможности разделять жгуты Vin, LOAD#, CAN и Ethernet от чувствительных ADC/I2C/SPI трасс.
  • Оставить сервисный зазор над FMUv6X/uMODULE и дочерними модулями.

Рекомендации по питанию ​

  • Добавить upstream fuse или eFuse перед Vin1; одного TVS недостаточно без источника с ограничением тока.
  • Добавить защиту от переполюсовки перед платой.
  • Проверить настройку выходного напряжения DC/DC-модуля до подачи питания на плату.
  • Не питать 5V от USB-C или внешних разъёмов без проверки путей обратного питания.
  • Добавить bulk capacitance рядом с силовыми нагрузками и определить flyback/surge clamps для индуктивных клапанов.
  • По возможности разделить грязное полевое питание и логическую землю; до интеграции в машину определить схему заземления.
  • Для длинных жгутов добавить CAN TVS, common-mode choke при необходимости, Ethernet ESD/magnetics и EMI-фильтрацию на границе корпуса.
