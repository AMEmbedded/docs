AM_CONTROL_NODE_V2 hardware ​

Черновик составлен по предоставленной принципиальной схеме и чертежу платы. Пункты TBD нужно уточнить по Altium-проекту, BOM, даташитам или результатам измерений перед релизом.

Status: NO HW NO FW

Назначение ​

AM_CONTROL_NODE_V2 - вторая версия интерфейсно-силовой платы для связки с управляющим модулем и внешней периферией. Плата объединяет ввод питания, измерение входного напряжения и тока, дискретные промышленные I/O, каналы управления нагрузками/клапанами, разъёмы концевиков, разъёмы 4–20 mA датчиков и интерфейсы FMU.

Плата может использоваться в одном из двух режимов:

  • uNODE mode — работа от uNODE MODULE V2 на базе STM32F103T8. Используется для локального управления нагрузками, концевиками, 4–20 mA датчиками, MAX14906 и INA228.
  • FMU mode — работа от FMU-модуля на базе STM32H753IIK6. В этом режиме доступны FMU-интерфейсы, включая Ethernet PHY, USB и две CAN-линии.

Важно: режимы выбираются альтернативно — в зависимости от задачи используется либо uNODE MODULE V2, либо FMU-модуль как основной контроллер платы. ETH PHY (LAN8742A), USB и две внешние линии CAN1/CAN2 доступны только в FMU mode.

Features ​

  • Основной вход питания через XT30.

  • Встроенный DC/DC-преобразователь 5 V от Vin_in.

  • Измерение входного питания:

    • ADC_V_IN — измерение входного напряжения через делитель.
    • ADC_A_IN — измерение входного тока через INA169 и шунт 1 mΩ.

  • Локальные 3.3 V LDO для доменов питания/управления, MAX14906 и Ethernet PHY.

  • Два альтернативных варианта контроллера платы:

    • uNODE MODULE V2 на STM32F103T8;
    • FMU-модуль на STM32H753IIK6.

  • Две CAN-линии с трансиверами TJA1042 и посадочными местами под 120 Ω терминаторы — только для FMU mode.

  • USB Type-C как USB 2.0 device-интерфейс — только для FMU mode.

  • Ethernet PHY LAN8742A по RMII с внешним 8-контактным Ethernet/Livox-style разъёмом — только для FMU mode.

  • 4 канала управления электрогидроклапанами/нагрузками: MVLC1…MVLC4.

  • BYPASS-режим для проброса сигнала джойстика напрямую на электрогидроклапан. В выключенном состоянии платы BYPASS включён аппаратно через твердотельное реле.

  • 4 микросхемы MAX14906 для линий концевиков: измерение состояния, управление питанием линий и диагностика обрыва питания.

  • INA228 для измерения токов и напряжений в LOAD1…LOAD4 и на входах C_SENS1…C_SENS4.

  • Разъём uNODE MODULE V2 для локального управляющего модуля.

  • Разъёмы концевиков: SENS1…SENS8.

  • Разъёмы датчиков 4–20 mA: C_SENS1…C_SENS4.

  • Разъёмы нагрузок/электрогидроклапанов: LOAD1…LOAD4.

  • Габарит платы: 82.5 mm × 98.5 mm.

Functional blocks ​

Power input and conversion ​

Vin_in приходит через XT30 и питает DC/DC module DCDLMR16030, формирующий 5 V rail. На плате также есть TVS-защита, bulk-конденсаторы, диоды/ORing-элементы и power-enable/control nets NPOWER_IN_A/B/C.

Input voltage and current measurement ​

Плата отдаёт два аналоговых сигнала для мониторинга входного питания:

SignalИсточникНазначение
ADC_V_INДелитель от VinИзмерение входного напряжения.
ADC_A_ININA169 + 1 mΩ shuntИзмерение входного тока.

CAN interface ​

CAN1 и CAN2 построены на TJA1042TK/3 с питанием 5 V. Эти две внешние CAN-линии доступны только в FMU mode. В схеме присутствуют 120 Ω терминаторы. В системе нужно проверить, является ли плата концом CAN-сегмента; если нет — терминатор не должен быть установлен/активен.

Ethernet interface ​

LAN8742A подключён к FMU по RMII и используется только в FMU mode. Используется кварц 25 MHz и внешний Ethernet connector. ETH_POWER_EN связан с цепями питания/управления PHY. По примечанию в схеме: R82 installed → PHY address 1; R82 DNP → PHY address 0 за счёт внутренней подтяжки вниз.

USB interface ​

USB Type-C работает как USB 2.0 device port и доступен только в FMU mode. Используются только D+/D− и VBUS sense. SuperSpeed-линии не используются. CC1/CC2 имеют Rd-резисторы.

Valve/load and sensor control ​

На плате есть 4 экземпляра Module Valve_Control и 4 разъёма LOADx для подключения электрогидроклапанов/нагрузок. Для LOAD1 зафиксированы ключевые линии разъёма:

PinSignalНазначение
2LOADВыход на электрогидроклапан.
3Operator Control InputВход сигнала от джойстика.

Модули нагрузки поддерживают BYPASS mode: сигнал с джойстика может быть проброшен напрямую на электрогидроклапан, минуя активное управление платы. При выключенной плате BYPASS включён автоматически аппаратно — через твердотельное реле, которое пропускает сигнал в обесточенном состоянии.

Из-за ограниченного количества выводов STM32F103T8 линия BYPASS объединена для LOAD3 и LOAD4.

SENS1…SENS8 — разъёмы концевиков. MAX14906 обеспечивает измерение состояния концевиков, управление питанием соответствующих линий и диагностику обрыва питания.

C_SENS1…C_SENS4 — входы для датчиков с токовым выходом 4–20 mA, где ток пропорционален измеряемой физической величине. Для этих входов используются INA228 и шунт 2 Ω.

Integration ​

Recommended mechanical mounting ​

  • Использовать все монтажные отверстия, показанные на чертеже платы.
  • Оставить зазоры вокруг боковых и верхних разъёмов под радиус изгиба жгутов.
  • Обеспечить механическую разгрузку XT30 и других разъёмов с высоким усилием подключения.
  • Не размещать проводящие элементы под платой без стоек и изоляции.
  • Проверить высоту сборки с FMU board-to-board connectors и корпусом.

Power Supply Recommendations ​

  • Подавать основное питание только через Vin1, если другой путь питания не был отдельно валидирован.
  • Перед включением проверить диапазон Vin_in относительно DC/DC module и требований нагрузок/клапанов.
  • Подбирать провода и предохранители под худший случай: суммарный ток всех LOADx + потребление платы.
  • Согласовать экраны и земли CAN/Ethernet/USB с общей схемой заземления аппарата.
  • Проверить inrush current и поведение коммутации на реальных клапанах/нагрузках.
  • Не оставлять CAN termination, если плата не находится на конце сегмента CAN.

Firmware notes ​

  • В прошивке должен быть выбран один целевой режим платы: uNODE mode на STM32F103T8 или FMU mode на STM32H753IIK6.

  • CAN1/CAN2, Ethernet LAN8742A и USB доступны только в FMU mode:

    • CAN1/CAN2 настраиваются через FDCAN-пины FMU;
    • Ethernet настраивать как RMII с PHY LAN8742A;
    • USB настраивать как FS device с D+/D− и VBUS sense.

  • Для LAN8742A проверить адрес PHY:

    • R82 installed → PHY address 1;
    • R82 DNP → PHY address 0.

  • MAX14906 управляются через SPI. Все устройства используют общие SDI, SDO, CLK, nCS1, SYNCH; адрес задаётся A0/A1.

  • Для MAX14906 реализовать:

    • чтение состояния концевиков через S0/S1;
    • управление питанием линий концевиков через S0V/S1V;
    • диагностику обрыва питания линии датчика;
    • обработку nFAULT и nREADY.

  • Для LOAD1…LOAD4 реализовать управление нагрузкой и BYPASS. Учесть, что BYPASS для LOAD3 и LOAD4 общий.

  • При выключенной плате BYPASS должен рассматриваться как аппаратно активный: сигнал Operator Control Input пробрасывается на электрогидроклапан через твердотельное реле.

  • INA228 доступны по I2C:

    • 8 адресов заняты измерением INA_OUT/INA_OCIN в LOAD1…LOAD4;
    • 4 адреса заняты входами C_SENS1…C_SENS4;
    • шунт для токовых измерений — 2 Ω.

  • Для ADC_V_IN и ADC_A_IN нужна калибровка по фактическому делителю, INA169 gain, шунту, ADC reference и допускам компонентов.

  • Добавить startup sequencing для NPOWER_IN_A/B/C и ETH_POWER_EN согласно выбранному режиму работы и финальному power tree.

Bring-up checklist ​

  • Визуальная проверка: полярность XT30, USB-C, CAN, Ethernet, load и sensor connectors.
  • Без питания: проверить сопротивления между Vin_in, 5V, 3V3 и GND.
  • Первое включение от лабораторного БП с ограничением тока: проверить 5 V и все 3.3 V rails.
  • Проверить масштабирование ADC входного напряжения и тока.
  • Для FMU mode: проверить CAN1/CAN2, RX/TX и конфигурацию терминаторов.
  • Для FMU mode: проверить USB enumeration через Type-C.
  • Для FMU mode: проверить доступ к LAN8742A по MDIO и PHY address.
  • Просканировать I2C и подтвердить адреса INA228 для LOAD1…LOAD4 и C_SENS1…C_SENS4.
  • Проверить SPI-связь с MAX14906, nREADY, nFAULT, состояние концевиков и диагностику обрыва питания линий.
  • Проверить BYPASS для LOAD1…LOAD4, отдельно учесть общий BYPASS для LOAD3/LOAD4.
  • Протестировать каждый LOADx, SENSx, C_SENSx канал на токограниченной нагрузке до подключения финальных актуаторов.
