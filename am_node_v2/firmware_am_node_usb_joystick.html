am_node_usb_joystick ​

Плата: AM_NODE_V2, исполнение H7.

Прошивка принимает из шины CAN команды джойстиков AM_JOYSTICK и отдаёт их компьютеру по USB как один HID-джойстик. Драйвер не нужен: Windows, Linux и macOS видят обычный игровой контроллер, браузер — через Gamepad API. Так джойстики стенда можно подключить к компьютеру без адаптера CAN и без ROS.

Отчёт уходит при каждом изменении входов; джойстики публикуют 20 раз в секунду. Виртуального COM-порта у этой прошивки нет.

Оси и кнопки ​

Каждая ось и кнопка HID берёт значение из uavcan.equipment.actuator.ArrayCommand со своим actuator_id. По умолчанию раскладка совпадает с номерами джойстиков стенда: левому отдана сотня 1xx, правому — 2xx.

Команда от −1 до +1 растягивается на всю ось, кнопка нажата при команде от 0,5. В HID ось Y растёт к оператору, поэтому у Y и Ry по умолчанию включён reverse: джойстик вперёд даёт минус оси, как у любого игрового контроллера. Прошивка принимает только команды с command_type 0 (без единиц) и конечным значением.

Потеря связи ​

Если по входу нет команды дольше usb_joystick.timeout_ms (500 мс), ось встаёт в ноль, а кнопка отпускается. Пропавший джойстик выглядит для компьютера как джойстик в нейтрали, поэтому о потере связи сообщает только статус узла в CAN.

Запуск ​

  1. Собрать прошивку: make am_node_h7_usb_joystick.
  2. Загрузить её через загрузчик по CAN, как описано ниже.
  3. Если на плате до этого стояла другая прошивка, сбросить параметры к значениям по умолчанию (Erase), сохранить их (Store) и перезапустить узел. Параметры лежат во внешней FRAM и после смены прошивки читаются по новой таблице: без сброса входы получат чужие значения, например actuator_id 0.
  4. Подключить плату к компьютеру кабелем USB-C и подвигать ручку: в системе появится AM USB joystick.

Обновление прошивки ​

Прошивка обновляется через bootloader по CAN с помощью GUI-инструмента:

  1. Подключи плату к питанию и CAN-шине.
  2. Открой GUI-инструмент и выбери нужный узел.
  3. Выбери .bin файл прошивки.
  4. Запусти обновление и дождись завершения загрузки.
  5. После перезапуска проверь, что узел снова появился в сети.

Если обновление не начинается, сначала проверь питание, CAN-H/CAN-L, общий GND, терминаторы и отсутствие конфликта uavcan.node.id.
