# Assets

Requirements:

- Use lowercase file names with underscores.
- Prefer `.webp` for board photos and rendered previews.
- Keep board preview images at or below `800x600`.
- Keep each image below `200 KB`.
- Use stable paths like `assets/devices/am_test_ina234.webp`.
- Do not commit raw camera dumps, design source files, archives, or multi-MB images.
