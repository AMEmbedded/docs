AM_CAN_LOGGER — руководство пользователя ​

Состав комплекта ​

В комплект входят:

  • Контроллер CUAV Pixhawk V6X с прошивкой AM_CAN_LOGGER.
  • Два кабеля для подключения к CAN-шинам станка: CAN_H, CAN_L и GND.
  • Wi-Fi-модуль CUAV PW-Link, подключённый к порту TELEM1.
  • Преобразователь DC/DC для питания регистратора от бортовой сети станка.
  • USB-кабель для подключения к компьютеру.
  • Набор наклеек двустороннего скотча для крепления контроллера к раме станка.
  • USB-HUB с ETH и кардридером для микро SD карты

Наклейки двустороннего скотча на фотографии не показаны.

Разъёмы и распиновка ​

PW-Link подключается к TELEM1, преобразователь питания — к POWER C1, кабели шин станка — к CAN1 и CAN2. Нумерация контактов приведена по схеме разъёмов CUAV Pixhawk V6X. Перед подключением сверяйте положение контакта 1 со схемой: при взгляде на ответную часть кабеля расположение контактов зеркальное.

КонтактTELEM1POWER C1CAN1CAN2
1+5 В+5 В, вход питания+5 В+5 В
2TX, передача от контроллера+5 В, вход питанияCAN1_HCAN2_H
3RX, приём контроллеромCAN_H модуля питанияCAN1_LCAN2_L
4CTS, управление потокомCAN_L модуля питанияGNDGND
5RTS, управление потокомGND——
6GNDGND——

Для PW-Link используются питание +5 В, GND и линии UART: TX контроллера соединяется с RX модуля, RX контроллера — с TX модуля. К сети станка подключаются только CAN_H, CAN_L и GND; контакт +5 В разъёмов CAN1 и CAN2 к сети станка не подключается. Питание от бортовой сети подаётся через комплектный DC/DC-преобразователь; подавать бортовое напряжение напрямую на POWER C1 нельзя.

Подключение к дэшборду ​

Дэшборд работает через приложение AM CAN logger tools: оно запускает серверную часть на компьютере или телефоне и показывает данные регистратора. Сначала скачайте приложение для своей системы, затем подключитесь к регистратору и запустите его. Устанавливать Python отдельно не требуется.

Скачать приложение ​

За актуальными файлами приложения обратитесь к разработчику.

Для описанного ниже порядка работы используется сборка v0.5.0 от 8 октября 2026 года, коммит 9761e5ac. В сообщении со сборкой она обозначена как AM CAN logger tools v0.5.0: Linux AppImage, Windows app, Android app и DEV BUILD • main, базовый тег — v0.5.0. Скачайте один файл для своей системы:

СистемаФайлПодготовка к запуску
Windows 10 и новее, x64am_canlog-v0.5.0-windows-x64.exeСохраните EXE на компьютере; установка не требуется.
Linux, x86-64am_canlog-v0.5.0-linux-x64.AppImageРазрешите выполнение файла как программы в его свойствах.
Android 7 и новее, ARM64am_canlog-v0.5.0-android.apkОткройте APK и установите приложение; при запросе разрешите установку из выбранного источника.

Скачайте файл заранее: точка доступа PW-Link служит для связи с регистратором и не предоставляет доступ в интернет.

Выбрать подключение: Wi-Fi или USB ​

После включения питания регистратора подключённый к TELEM1 модуль PW-Link создаёт точку доступа Wi-Fi. Находясь рядом с устройством, откройте список сетей на компьютере или телефоне и найдите имя вида CUAVWLink_XXXXXX. Окончание имени отличается у каждого модуля; на примере ниже видны два PW-Link, поэтому при наличии нескольких устройств выбирайте сеть нужного регистратора. Пароль по умолчанию — cuavwlink, если он не был изменён при подготовке комплекта (документация CUAV). Дождитесь подключения к сети; если система предупреждает об отсутствии интернета, выберите сохранение подключения к этой сети.

На компьютере вместо Wi-Fi можно подключить регистратор комплектным USB-кабелем. Для приложения Android в этом руководстве используется подключение по Wi-Fi. После выбора Wi-Fi или USB порядок работы с дэшбордом одинаков: запустите приложение и проверьте подключение в верхней панели. При работе по USB закройте QGroundControl и другие программы, которые могут занимать порт регистратора.

Запустить приложение ​

В Windows дважды щёлкните am_canlog-v0.5.0-windows-x64.exe; в Linux запустите am_canlog-v0.5.0-linux-x64.AppImage. Приложение запускает локальный сервер и автоматически открывает страницу дэшборда в браузере. Если вкладка не появилась, откройте http://localhost:8080 на том же компьютере. На Android откройте установленное приложение AM CAN logger: дэшборд появится внутри приложения.

На компьютере при первом запуске режим auto выбирает подключённый по USB регистратор, а при его отсутствии — Wi-Fi через UDP, порт 14550. При следующих запусках приложение использует ранее выбранное подключение. Если данные не появляются, нажмите на индикатор подключения рядом с названием дэшборда и выберите auto, нужный USB-порт или UDP для Wi-Fi. При первом запросе брандмауэра Windows разрешите приложению сетевой доступ: он необходим для получения данных через PW-Link.

В Windows сервер работает как фоновый процесс и не имеет отдельного окна. Чтобы найти его, откройте диспетчер задач сочетанием Ctrl+Shift+Esc, перейдите в «Процессы» и введите am_canlog в поиск. На примере ниже имя файла отличается от версии в таблице, но процесс узнаётся по началу am_canlog.

Для обычного завершения используйте кнопку Quit в дэшборде; локальное приложение также останавливается при закрытии последней вкладки панели. При необходимости процесс можно остановить через диспетчер задач: выберите am_canlog и нажмите «Завершить задачу». После остановки сервера локальная панель недоступна, но регистратор продолжает автономную запись при наличии питания.

Что отображается в дэшборде ​

После установления связи появятся список записей и текущие показания регистратора. На скриншоте показано подключение по USB: индикатор auto · COM5 в верхней панели. Номер COM-порта на другом компьютере может отличаться.

  • Верхняя панель: название и версия приложения, выбранное подключение, число подключённых клиентов, поток кадров и данных, загрузка CPU регистратора, свободное место на карте памяти; справа — кнопки доступа к публикации панели и настройкам.
  • Слева — записи: вкладка On the card показывает сессии на карте регистратора, On this computer — сохранённые на компьютере; для сессий видны время, объём и отметки событий, а текущая запись помечена recording.
  • Справа — текущие показания LIVE: во вкладке Charts отображаются загрузка CAN1 и CAN2, поток записи на SD-карту и вибрации; кнопки 2 min, 10 min, 30 min выбирают интервал графиков, кнопка паузы приостанавливает их обновление.
  • Над графиками: поле Event marker и кнопка Mark для фиксации событий; рядом с Charts находится вкладка Sniffer для просмотра CAN-трафика.
