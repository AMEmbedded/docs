AM_EVAL_JOYSTICKS ​

Status: EVAL

Evaluation board for joystick and operator-control input bring-up on STM32F103.

Main interfaces:

  • CAN;
  • I2C on PB6/PB7;
  • board power/current ADC inputs;
  • joystick-related input pins.

Pinout ​

PinSignalMCU configuration
PA10BT1 / LIVE_NGPIO input
PA9BT2 / INC_NGPIO input
PB0BT3 / DEC_NADC1_IN8
PB3SWA1 / LEFT_N relayGPIO input

PA2OUT1 / sideADC1_IN2

PA9, PA10, PB3, and PB4 are not ADC-capable pins on STM32F103 and are configured as GPIO inputs.

Bring-up notes ​

Current joystick observations:

  • cid=1 (eval.pa10_bt1_live_n.cid) is BT1/LIVE_N: 0 V live, 3.3 V dead.
  • cid=2 (eval.pa9_bt2_inc_n.cid) is BT2/INC_N: 0 V increased, 3.3 V otherwise.
  • cid=3 (eval.pb0_bt3_dec_n.cid) is BT3/DEC_N: 0 V decreased, 3.3 V otherwise.
  • cid=4 (eval.pb3_swa1_left_n.cid) is SWA1/LEFT_N relay: 0 V slightly left, 3.3 V otherwise.
  • cid=5 (eval.pb4_swa2_relay.cid) is SWA2 relay: always 3.3 V during bring-up.
  • cid=6 (eval.pa2_out1_side.cid) is OUT1/side: 0 V left, about 3.0 V right.
  • cid=7 (eval.pa5_out2_travel.cid) is OUT2/travel: about 3.0 V forward, 0 V backward.
  • cid=8 (eval.pa6_out3_diag.cid) is OUT3/DIAG: constant about 1.7 V during bring-up.
  • cid=10 (eval.pa4_3swa_back_n.cid) is 3SWA/BACK_N relay: 0 V slightly backward, 3.3 V otherwise.
  • cid=11 (eval.pa3_4swa_fwd_n.cid) is 4SWA/FWD_N relay: 0 V slightly forward, 3.3 V otherwise.
  • OUT3 is DIAG for sure; DIAG behavior needs re-check after the latest hardware change.
  • Buttons and other joystick features do not work or have not been identified yet.
